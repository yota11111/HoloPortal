# Milestones

## M1: 公開準備

Status: done

- GitHub Pages向けワークフローを用意する。
- Repository Secret `HOLODEX_API_KEY` を設定できる形にする。
- READMEに開発、確認、公開、運用手順をまとめる。

## M1.5: Codex/Copilot併用体制

Status: done

- Codexを設計、レビュー、難所判断に寄せる。

- アーキテクチャ、開発手順、タスクキューをドキュメント化する。
- 各タスクに受け入れ条件と検証コマンドを付ける。
